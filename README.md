# ZDuo

用 MacBook 的真实屏幕角度控制桌面的透视和渐进离焦，模拟“画面停留在原平面，屏幕向它靠近或离开”的开合过渡。原生 Swift 初版 demo，支持滑杆模拟。

## 启动

已构建的应用位于 `dist/ZDuo.app`，双击即可打开。它是菜单栏应用，没有 Dock 图标；首次启动会展示控制面板，效果默认关闭。

重新构建前请先退出正在运行的 ZDuo，然后执行：

```bash
./scripts/build.sh --run
```

需要 macOS 14 或更新版本、支持 Metal 的 Mac，以及 Swift 6 或更新的 Command Line Tools / Xcode。没有第三方依赖，无需安装完整 Xcode 或独立 Metal 编译工具。脚本使用 SwiftPM native 构建引擎，以适配仅有 Command Line Tools 的环境；新工具链可能提示该引擎已弃用，这不影响当前构建。

## 使用

1. 打开启用开关。首次运行时，允许 ZDuo 使用“屏幕与系统音频录制”中的**屏幕录制**权限；应用不录制声音。
2. 如果系统要求手动授权，在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中开启 ZDuo，然后点击“重新检查”。系统要求重新启动时，退出并重新打开同一个 `ZDuo.app`。
3. 默认选择“真实开合”，保持底座和观察位置相对稳定，轻轻把屏幕合至 **110° 以下**。越接近闭合，顶部离焦越强；底部铰链附近较清晰。
4. 屏幕停住，景深保持；重新打开到参考角度，立即恢复真实桌面。
5. 选择“滑杆模拟”可以不动屏幕体验 15°–150° 的过渡。模拟模式仍需要桌面捕获权限。

“参考角度”可调 30°–150°；“设为当前”使用当前输入角度。“效果强度”为 0–100%。参考角度和强度会保存，启用状态不会保存。

### 停用与退出

- **`⌃⌥⌘D`（Control + Option + Command + D）立即停用效果**，无需辅助功能或输入监控权限。若快捷键被其他应用占用，面板会提示。
- 点击菜单栏笔记本图标打开／收起面板。右键菜单可停用效果或退出。
- 设置界面是普通窗口，可以被其他窗口遮挡和最小化，不置顶，也不跟随所有桌面。
- 菜单展开或设置窗口获得焦点时临时透出真实桌面，保证界面可见且点击对齐；收起设置窗口或切换到其他窗口后恢复效果。
- 收起面板不会停用效果。“退出”会撤掉覆盖层并停止应用。

## 实现

数据流：`IOKit 铰链传感器 / 模拟滑杆 → 角度平滑 → FoldCore 效果参数 → ScreenCaptureKit + Metal → 内置屏幕覆盖窗口`。

- **角度**：匹配 Apple HID `Vendor 0x05AC / UsagePage 0x20 / Usage 0x8A`，读取 Feature Report 1，每秒约 30 次轮询，角度使用 12–35 ms 自适应平滑：小幅变化抑制量化台阶，较大变化加快跟随。传感器协议并非 Apple 公开承诺的接口，支持情况因机型而异。本机已验证可读取。
- **平面**：对齐 [Hinge 的原始投影](https://github.com/Noveum/hinge/blob/main/Resources/Fold.metal)：满高度、底部锚定、`taper = 0.30 × progress`，顶部裁剪为 `cos(0.65 × 90° × progress)`。几何进度按参考角度至 8° 映射；默认参考 110°、强度 100% 时，85° / 60° / 30° 的顶部宽度约为 93% / 87% / 81%。恢复轻微收窄以减少画面随物理屏幕一起转动的观感。这是固定观察点的视觉近似，并非严格的空间固定平面；传感器和平滑仍使用 ZDuo 现有逻辑。
- **离焦**：先在捕获分辨率绘制透视和两侧填充，再复用 Metal Performance Shaders，在宽度最多 1280 px 的纹理上生成旧版的 4 / 12 / 28 pt 三档高斯散射。模糊发生在物理屏幕坐标中，避免合盖时被透视拉成长条；从铰链附近的轻微离焦向顶部逐渐增强。
- **两侧填充**：虚拟屏幕以外的区域使用独立的 36 pt 宽模糊桌面背景，按屏幕坐标采样，不重复拉伸最边缘的文字像素。背景仅在新捕获帧或尺寸变化时更新；随合盖逐渐压暗，最大降低约 55% 的 RGB 强度，边缘柔和过渡。
- **物理屏幕磨砂**：恢复 2026-09-18 22:44 的提交 `2919cde`（最接近用户提到的 22:46 版本）：冷灰色调、顶部最高 44% 的柔和覆盖、宽反光和静态细颗粒，向铰链渐淡。材质保留原先参考角度至 15° 的渐变节奏，与 Hinge 几何进度分开计算；零强度时完全还原。
- **捕获**：ScreenCaptureKit 实时捕获内置屏幕，目标 30 fps，排除整个 ZDuo 应用，避免递归捕获。MTKView 目标 60 Hz，只在有新画面或参数变化时提交绘制。
- **渲染成本**：新帧或角度变化时重新计算透视与屏幕空间模糊，复用纹理和 MPS kernel。相较旧版仅混合已有模糊层，转动时 GPU 工作量有所增加；真实桌面上的持续帧率与功耗仍需实测。
- **生命周期**：获得首帧并完成 GPU 渲染后才显示覆盖。角度归零、停用、锁屏、睡眠、镜像或设备异常时撤下覆盖；停用时停止捕获和绘制。唤醒后等待屏幕稳定并获取新帧。

源码分为 `FoldCore`（纯角度计算与可用性判定）和 `ZDuo`（输入、捕获、渲染、界面）。关键数学与资源生命周期有中文注释。

## 验证

```bash
# 角度曲线、投影、平滑、传感器报告及故障退出条件
./scripts/test.sh

# 只读检查传感器和权限，不触发录屏授权
dist/ZDuo.app/Contents/MacOS/ZDuo --diagnose

# 在真实 GPU 上渲染自建测试图，不读取桌面、不需要屏幕录制权限
dist/ZDuo.app/Contents/MacOS/ZDuo --render-check .build/render-check
```

GPU 检查导出 110°、109°、100°、85°、60°、30°、15°、8° 的 PNG，校验参考角度处与输入图逐像素一致（允许 1/255 误差）、无透明空洞、反向一致和零强度还原。额外用坐标色卡检查 CPU/GPU 投影一致（允许 2/255 误差），用暗灰色卡对照 22:44 版本的五个垂直渐变采样值。

侧边回归检查使用左右贴边的细亮线模拟侧栏文字，在参考 118°、实际 108° / 85° / 60° 时验证填充区域没有横向条纹拖尾，并导出 `sidebar-*.png`。

实机验收建议：

- 使用滑杆缓慢往返、快速反向、半开停留，观察是否跳变、闪烁或出现残留覆盖。
- 真实开合与模拟在同一角度呈现一致效果；回到参考角度时桌面恢复正常。
- 未授权时保持原桌面；授权后重试成功；全局停用快捷键立即生效。
- 锁屏／睡眠后恢复不显示旧桌面；镜像时暂停；外接屏不被覆盖。
- 普通应用、全屏应用和菜单均可恢复正常操作。

## 当前边界

- 仅处理可用的**内置屏幕**；外接屏、镜像显示和受保护系统界面不做效果。没有可用传感器时可选择滑杆，但仍需要内置屏幕。
- 这是固定观察点的视觉近似，没有头部追踪。变形期间鼠标仍命中原应用坐标，适合观察开合过程，精确操作前请恢复清晰或停用。
- 不改变 macOS 合盖睡眠行为。传感器读数 ≤5° 时也会隐藏效果；完全合盖后重新打开，要等系统唤醒和捕获准备就绪，无法接管系统唤醒动画。
- 画面使用 SDR；受保护的视频可能显示为空白。
- 屏幕帧只驻留本机内存，不保存、不上传；无网络、摄像头、麦克风、开机启动项或后台服务。
- 本地应用采用临时签名，未公证或上架。重新构建后若系统权限失效，需要在屏幕录制设置中移除旧 ZDuo 条目，再用「＋」添加当前 `dist/ZDuo.app`；仅反复开关旧条目可能仍然匹配旧签名。不要同时运行多个构建副本。

## 参考

- [Apple ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos/)：实时屏幕采集。
- [LidAngle](https://github.com/deepakness/LidAngle)：HID 铰链传感器的公开实现参考。
- [Apple MPSImageGaussianBlur](https://developer.apple.com/documentation/metalperformanceshaders/mpsimagegaussianblur)：本项目直接复用的 GPU 高斯模糊，无需新增第三方依赖。
- [Microsoft Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)：先前材质实验的分层参考，当前按用户偏好恢复历史渐变；没有引入 Windows 组件或复制其源码。
- [Glur](https://github.com/joogps/Glur)：基于 Metal 的 SwiftUI 渐进模糊库，支持方向、遮罩与噪声。适合 SwiftUI 内容；当前桌面画面走 MTKView，因此保留现有 MPS 管线。其独立 GlurBackdrop 产品使用私有 API，本项目未引入。
- [MetalPetal](https://github.com/MetalPetal/MetalPetal)：基于 Metal 的图像处理框架，适合后续更复杂的滤镜链。当前已有所需的 MPS 功能，本次不增加框架依赖。
